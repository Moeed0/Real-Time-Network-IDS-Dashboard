# Independent IDS Alert Samples

This folder contains three Snort alert JSON records and three Suricata EVE
alert records. The samples are intended for parser, normalizer and dashboard
development.

These are standalone samples, not a correlation dataset. Correlation IDs,
Community IDs, flow IDs, related-alert records and capture-specific identifiers
have been removed. Source and destination addresses use documentation-only IP
ranges. Potentially sensitive HTTP fields have been redacted.

These alert records are not a full packet capture and do not prove that an
attack succeeded.
